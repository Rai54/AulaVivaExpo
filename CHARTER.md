# CHARTER — AulaViva

## Propósito

Desarrollar AulaViva, una plataforma SaaS multi-tenant orientada a la educación, que permita a colegios gestionar cursos, docentes y estudiantes, realizar evaluaciones automáticas y utilizar un tutor IA con contexto curricular.

## Definition of Done (DoD)

Una tarea se considera terminada cuando:

- El desarrollo cumple con los requisitos definidos.
- El código fue revisado mediante Pull Request.
- Se realizaron las pruebas correspondientes.
- No existen errores críticos conocidos.
- La documentación necesaria está actualizada.
- Los cambios fueron aprobados por el equipo.

## Política de IA

El equipo podrá utilizar herramientas de inteligencia artificial como apoyo para programación, documentación, investigación y generación de ideas.

Todo contenido generado mediante IA deberá ser revisado y validado por un integrante del equipo antes de incorporarse al proyecto.

No se ingresarán datos personales, credenciales, contraseñas ni información sensible de usuarios en herramientas de IA.

## Canal de comunicación

El equipo utilizará Slack como canal principal de comunicación.

Las decisiones importantes relacionadas con el proyecto deberán quedar registradas en GitHub.

## Reglas de trabajo

- Las tareas se gestionarán mediante Issues.
- El trabajo se organizará mediante el tablero Kanban.
- Los cambios se realizarán mediante Pull Requests.
- No se realizarán cambios directamente sobre `main`.
- Las reuniones y decisiones importantes serán comunicadas por Slack.
- Cada integrante deberá mantener actualizada la información de sus tareas.
