# Escenarios de aceptación - AulaViva

Los escenarios están escritos utilizando Gherkin como parte de una estrategia BDD (Behavior Driven Development).

Cada archivo representa una historia de usuario definida en el backlog.

| Archivo | Funcionalidad | Actor |
|---|---|---|
| US-01.feature | Tutor IA con contexto curricular | Estudiante |
| US-02.feature | Evaluaciones automáticas | Estudiante |
| US-03.feature | Gestión académica RBAC | Docente |
| US-04.feature | Seguimiento académico | Apoderado |
| US-05.feature | Aislamiento multi-tenant | Coordinador académico |

## Formato utilizado

- **Given:** Contexto inicial.
- **When:** Acción realizada.
- **Then:** Resultado esperado.

Los escenarios permiten validar que cada funcionalidad cumpla con los criterios definidos antes de su implementación.
